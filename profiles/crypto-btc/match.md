# Bitcoin 投资决策 profile

当一条内容的**首要价值**是帮助一位持有或准备持有 BTC 的投资者判断当前市场状态、风险与仓位时，使用此 profile。

## 属于此 profile

- **价格与市场结构**：关键价位突破/失守、成交量与流动性变化、现货与合约基差、资金费率、清算规模、多空比、ETF 净流入流出、期权持仓与最大痛点。
- **链上数据**：活跃地址、交易数、交易所净流入/流出、长期持有者持仓变化、矿工持仓与算力难度调整、已实现盈亏、MVRV/SOPR 等估值指标的实际读数与拐点。
- **监管与政策**：SEC/CFTC 的执法与批复、各国税收与合规框架、ETF 申赎规则变化、储备资产立法、交易所合规处罚。**必须说明具体条款或生效时间**，笼统的「某国监管趋严」不算。
- **机构与资金面**：上市公司与 ETF 持仓变动、矿企财报与减半后的成本结构、托管与清算基础设施变化、大额地址转账。
- **技术协议与升级**：Bitcoin Core 版本与共识变更、软分叉提案进展（如 CHECKTEMPLATEVERIFY、CTV）、闪电网络容量与通道数、Taproot 生态、Ordinals/Runes 对区块空间与手续费的影响。
- **风险事件**：交易所被盗或暂停提现、协议级漏洞、稳定币脱锚对 BTC 的传导、矿池算力集中度、系统性杠杆爆仓。
- **可验证的观点**：有具体数据支撑的多空论证、知名分析师或机构的仓位与理由（须标明是观点而非事实）。

## 不属于此 profile

- **无实质信息的行情复读**：「BTC 突破 X 万美元」这类只有价格没有驱动因素的一句话快讯。
- **纯技术分析画线**：没有数据或事件支撑的形态预测、玄学指标。
- **Meme 币、山寨币、NFT、GameFi**：除非明确说明它对 BTC 流动性的传导机制，否则归入其他 profile。
- **交易所营销、空投、拉新活动、返佣推广**。
- **价格预测口号**：「明年 50 万」这类没有论证基础的喊单。
- **入门科普**：「什么是比特币」「如何创建钱包」这类长期有效的基础教育内容。
- **与投资决策无关的区块链应用新闻**：供应链溯源、政务链等.

## 与 tech-news 的分界

技术协议升级（如新的软分叉提案）如果**主要影响开发者生态**，归 tech-news；如果**主要影响持币者的估值或风险**，归本 profile。判断标准：一个只关心价格的持币者会不会因此改变仓位或预期。
