# AI 应用与 Agent 实践 profile

当一条内容的**首要价值**是帮助读者把 AI 用起来——理解某个模型/工具/Agent 框架的实际能力、使用方式、成本、局限——时，使用此 profile。

## 属于此 profile

- **模型与产品发布**：新模型或新版本上线，重点是**可用的能力变化**：上下文长度、工具调用、结构化输出、多模态、价格、速率限制、区域可用性。附带 benchmark 但必须说明是什么任务上的分数。
- **Agent 框架与工程实践**：LangGraph、LlamaIndex、CrewAI、AutoGen、MCP 协议、OpenAI Agents SDK 等的实际用法、架构取舍、失败模式。工具调用可靠性、长任务编排、状态管理、重试与降级策略。
- **真实落地案例**：某公司或个人把 AI 接进具体工作流后的**量化结果**：节省多少时间、成本降多少、准确率变化、在哪些环节失败。带具体数字和踩坑细节的案例优先。
- **工作流与效率工具**：编码助手（Cursor、Claude Code、Copilot）、写作与研究工具、自动化平台的实际使用体验、额度与计费变化。
- **提示与上下文工程**：可复用的方法、评估手段、上下文管理策略。**必须是方法论**，不是零散提示词清单。
- **开源项目**：可自部署的 Agent 框架、RAG 工具、本地推理方案、MCP server。给出仓库地址与最低硬件/成本要求。
- **成本与经济性**：API 价格变动、自建 vs 托管的成本对比、token 消耗实测、推理延迟数据。
- **能力边界与失败案例**：什么场景下 AI 会稳定出错、评测揭示的短板、被证伪的炒作。

## 不属于此 profile

- **纯融资与估值新闻**：某公司融了多少钱、估值多少，没有产品能力或生态实质变化的。
- **公司人事与公关**：高管变动、发布会花絮、营销活动。
- **零散的提示词清单**：「50 个 ChatGPT 神提示」这类没有方法论支撑的收集。
- **无证据的趋势预测**：「2027 年 AGI 就会到来」这类没有可核对依据的判断。
- **入门教程**：「什么是大语言模型」「如何注册账号」。
- **纯学术论文**：除非它已经转化为可用工具或有清晰的工程含义。
- **AI 生成内容的作品展示**：生成的图片/视频/音乐本身，除非重点在方法或工具。

## 与 tech-news 的分界

同一件事，如果**主要是行业格局变化**（某公司收购某公司、某标准联盟成立），归 tech-news；如果**主要是「这东西我能怎么用」**，归本 profile。判断标准：一个开发者读完会不会想去试一下。

## 与 tech-blog 的分界

如果是**长篇工程深度复盘**（几千字讲清楚一个系统怎么搭的、为什么这么选），归 tech-blog；如果是**产品能力、工具用法、成本数据**这类偏实用的信息，归本 profile。
